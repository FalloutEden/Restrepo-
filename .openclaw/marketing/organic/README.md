# Organic post copy — pre-written drops

These are ready to paste, in BV brand voice. No emoji. Construction-led. Each post lists:
- The platform it's tuned for (caption length + tone)
- A suggested asset (use Content Studio or BG-composite to produce)
- Hashtag stack (curated — no broad #fashion #ootd spam)

When you finish content-studio image generation, you can pair these captions with the AI-generated lifestyle shots and post manually. Or feed them to the operator's `mark_content_post_posted` tool after publishing.

## Files

- `instagram-feed.md` — 7 captions for the IG main feed (square + portrait)
- `instagram-reels.md` — 5 captions for vertical short-form (15–30s)
- `tiktok.md` — 5 captions, native TikTok voice (≤150 char hook)
- `threads.md` — 6 short Threads-native posts (≤280 char)
- `pinterest-pin-text.md` — 8 Pin titles + descriptions for the BV boards

## Posting cadence (first 30 days)

| Platform | Cadence | Mix |
|---|---|---|
| Instagram feed | 3–4 posts/week | 60% editorial, 40% product |
| Instagram reels | 2–3 reels/week | Construction macros + lifestyle |
| TikTok | 5–7 posts/week (only platform that rewards volume) | Hook-led shorts |
| Threads | 1–2 posts/day | Casual brand voice; tease drops |
| Pinterest | 1–2 pins/day | Mostly editorial; product Pins linked |

Don't post the same caption verbatim across platforms — the algorithms penalize cross-posted text. Each file's captions are written for that platform's voice.
