# BV Influencer Seeding List — Initial 50 Targets

Goal: gift product to 50 micro-influencers (5k–50k followers) in the menswear / streetwear / "quiet luxury" buckets. ~10% organic post rate is the realistic baseline. Cost: ~$3-5k in actual product (Printful margin, not retail).

**This is a starter scaffold. The merchant should review each handle, verify still active, and personalize the DM before sending. Do NOT bulk-DM with the same script — IG flags it as spam.**

```
Built to be Kept.
— [Your name]
```

## How to use this scaffold

This is a frame, not a finished list. The right way to build it:

1. **Open IG** and search hashtags: `#menswear #quietluxury #darkaesthetic #premiumessentials #streetwearstyle #malefashionadvice #heavyweightcotton`
2. For each result with 5k-50k followers, check:
   - Last post within 14 days (active)
   - Aesthetic actually matches BV (not bright colors / loud branding / non-fitting style)
   - Posts have organic engagement (likes ≥ 5% of follower count is healthy)
   - Bio doesn't say "DMs not open for collabs" / "PR by [agency]"
3. Add their handle to one of the 7 buckets above + 1-2 sentences on why they fit
4. Pick top 50 across buckets

## Tools that speed this up

- **HypeAuditor** (free tier shows 5 results/day) — verifies follower authenticity
- **Aspire** (free tier discovers by hashtag/niche)
- **Modash** ($99/mo) — most comprehensive, worth it if you do this seriously
- Or **manual** for free — slow but most authentic, ~3 hrs to build the 50

## Pacing

- Week 1: build the 50-name list
- Week 2: send 50 DMs in batches of 10/day (IG rate-limits aggressive cold DM)
- Week 3: ~25 say yes, ship Printful orders to those addresses
- Week 4-6: ~5-15 organic posts/stories
- Week 8: measure direct attribution + repeat with new list

**Track in a Google Sheet:** handle, fit category, sent date, response, accepted Y/N, address provided, shipped date, posted Y/N, post URL, perceived engagement, repeat-buyer Y/N.

## Hard rules

- Don't pay for posts unless you've already validated organic — paid influencer posts have 70% lower conversion than organic
- Don't DM bigger accounts (50k+) cold — they ignore. Climb the ladder via micros first.
- Don't reuse the same DM verbatim — personalize at minimum the [first name] and [specific post] tokens
- Don't gift to handles that already work for competitors (Aimé Leon Dore, Buck Mason, etc.) — they're already locked in
