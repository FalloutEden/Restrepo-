# Pinterest — organic-first, paid-promote-the-winners

Pinterest is **the highest-margin discovery channel for premium apparel** because pinners save now and buy in 3–6 months. Pre-launch posture: seed organic Pins now, promote the top 3 once you have engagement data.

## Account setup

- [ ] Pinterest Business account claimed for `blackvaultapparel.com`
- [ ] Domain verified via DNS TXT
- [ ] Pinterest Tag installed via Shopify Pinterest Sales Channel app
- [ ] Catalog feed connected (auto-pulls from Shopify) — products show up as Product Pins automatically
- [ ] Rich Pins enabled (price + availability live on the Pin itself)

## Boards (create these on day 1, even before posting)

| Board name | Purpose |
|---|---|
| Black Vault — The Foundation | Brand-story Pins. Editorial shots, BV-mock-BG composites, no product links. |
| Built to be Kept | Product Pins. Each piece linked to its Shopify page. |
| Heavyweight Cotton | Niche board around the 10.3oz hoodie + 7.5oz tee — Pinterest rewards specificity |
| The Headwear | Snapback + beanie Pins, including AOP variants |
| Dark Aesthetic Menswear | Inspiration board (curated Repins from other brands) — Pinterest rewards activity, not just self-promotion |

## Pin templates (organic, 1000x1500 — the Pinterest aspect ratio)

### Pin Type A — Editorial Hero
- Visual: BV-mock-BG composite (model in The Hoodie, ¾ angle, lower 25% reserved for headline overlay)
- Title: `Built to be Kept.`
- Description: `Heavyweight 10.3oz organic cotton. Embroidered Old Gold monogram. Cut for the next ten years, not the next photo. — Black Vault Apparel`
- Link: blackvaultapparel.com

### Pin Type B — Construction Detail
- Visual: macro of the embroidered BV monogram, dramatic raking light
- Title: `Old Gold thread. Embroidered, not printed.`
- Description: `Every BV piece carries the monogram in chain-stitch embroidery, Pantone Old Gold (#A67843). Built to outlast trends.`
- Link: collection page

### Pin Type C — Specs (text-card)
- Visual: dark gradient background, white serif text laid out like a spec sheet
  ```
  THE HOODIE
  10.3oz organic cotton
  Stanley/Stella SASU024
  Embroidered, not printed
  $168 — built to be kept
  ```
- Description: same as Type A
- Link: hoodie product page

### Pin Type D — Lifestyle (no product visible)
- Visual: low-light editorial shot, model from the back, bv-mock-BG composite
- Title: `For the next ten years.`
- Description: short brand-voice line; **no spec details** — pure aesthetic
- Link: brand homepage

## Posting cadence

- **Week 1:** 3 Pins/day across the boards. Front-load Pin Type A (editorial hero) on the Built-to-be-Kept board.
- **Week 2+:** 1–2 Pins/day. Repin curated content (Dark Aesthetic Menswear board) once per day to keep the algorithm seeing activity.

Use Tailwind or the Pinterest native scheduler — manual posting eats too much time.

## Promoted Pins (paid)

After 14 days of organic, look at Pin analytics:
- Top 3 Pins by Outbound Clicks → promote with $5/day each
- Top 3 Pins by Saves → promote with $3/day each (lower CPM, optimizing for awareness)

Total monthly Pinterest paid spend cap: **$300/month** until paid CPA proves out.

Targeting for promoted Pins:
- US, age 25–55
- Interests: Men's Fashion, Streetwear, Designer Apparel, Luxury Lifestyle
- Keyword targeting: "premium hoodie", "heavyweight cotton tee", "minimalist menswear"

## Hard stops

- If a Promoted Pin gets > 1% CTR but < 0.1% conversion → product page is converting badly, not the Pin's fault. Audit the page.
- If $300 of paid pins drives 0 sales over 30 days, pause Pinterest paid entirely and stick to organic. Pinterest is the slow-burn channel; not every brand gets paid lift.
