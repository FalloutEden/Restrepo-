# BV launch marketing kit

Everything in this folder is **ready to deploy, not deployed**. Nothing here spends money on its own — the merchant chooses when to push each asset live.

## Layout

- `ads/` — paid-channel creative (Meta, TikTok, Google Shopping, Pinterest)
- `emails/` — Klaviyo / Shopify Email-ready campaign drafts
- `organic/` — short-form organic posts already drafted in BV voice (use to seed Content Studio if you want variants)
- `launch-day-checklist.md` — the order things should happen in on launch day

## Brand voice rails (apply everywhere)

- **Reads like:** Aimé Leon Dore, Saint Laurent menswear, Cuts Clothing, Kith. Dark, restrained, premium. Specific GSM and fabric details. Never inspirational-quote energy.
- **Tagline:** "Built to be Kept."
- **Avoid:** occupation-specific copy ("for nurses/veterans/dog dads"), motivational platitudes, generic "premium quality" claims, holiday gimmicks.
- **Always cite:** GSM, fiber composition, embroidery thread color (Old Gold #A67843), construction details when relevant.
- **Pricing posture:** premium ($42 hat → $168 hoodie). Don't apologize for price; lead with construction.
